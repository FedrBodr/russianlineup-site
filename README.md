# russianlineup-site

Сайт комьюнити «Русский Лайнап»: русскоязычные сёрферы на Шри-Ланке (юг зимой, Аругам Бэй летом), в Мысовом (винг-фойл) и в Москве/МО (электросёрф). Статический сайт без сборки, деплой из git по push в `master`.

## Что внутри

- `index.html` — главная комьюнити: направления, серф-кэмп, инструкторы, чаты.
- `elektroserf/index.html` — бывшая главная: лендинг электросёрфа (прокат, тест-день, продажа, корпоратив, форма заявки). Переехала с `/` 20.10.2026.
- `shri-lanka/`, `mysovoe/`, `instruktory/`, `instruktory/den/` — страницы направлений и инструкторов на общем `blog.css`.
- `bot.js` — скрипт кнопок `.js-bot` (диплинк в бота), копия скрипта с `/elektroserf/`. Нужен `window.SITE_CONFIG` на странице.
- `/camp/` здесь нет: серф-кэмп деплоится из репо SurfLanka в `/www/russianlineup.ru/camp/`. Сайт Оли — olyasurf.russianlineup.ru, тоже из SurfLanka. Не создавай здесь папку `camp/`.

- `index.html` — лендинг. Кнопки ведут в Telegram-бота (deep-link с UTM + склейка через ClientID Яндекс.Метрики).
- `favicon.svg`, `robots.txt`, `sitemap.xml`, `CNAME` — SEO/инфраструктура.
- Аналитика: Яндекс.Метрика (приоритет РФ/СНГ) + GA4 в `<head>`.

## Перед публикацией

Открой `index.html`, в блоке `window.SITE_CONFIG` подставь реальные значения и замени плейсхолдеры `[в скобках]`. Полный список — в `CONTENT_TODO.md`.

## Деплой

См. `DEPLOY.md` (push в `master` → автосборка).

## Связь с воронкой

Кнопки лендинга → бот с параметром `start=<источник>__<ClientID Метрики>`. Бот (этап 7) разбирает это и сшивает веб-сессию с действиями в Telegram — единая сквозная аналитика. Репозиторий бота: https://github.com/FedrBodr/ruslineup-bot

## Решения

- **20.10.2026 — главная стала сайтом комьюнити, электросёрф переехал на `/elektroserf/`.** Причина: бренд шире электросёрфа — чаты на Шри-Ланке, в Мысовом и в Москве, серф-кэмп и инструкторы. Электросёрф — летнее московское направление, ему достаточно своей страницы. Ссылки `/#testday` и др. со статей и лендингов переписаны на `/elektroserf/#...`. Отвергли: оставить электросёрф на главной и добавить комьюнити блоком (главная продолжала бы продавать одно направление).
- **Страницы направлений и инструкторов — на `blog.css`, без новой вёрстки.** Причина: быстро, единый стиль с блогом; контента пока мало.
- **Дэн: запись через бота (`data-src="instructor_den"`).** Причина: своего контакта Дэна на сайте пока нет, бот сохраняет атрибуцию.
- **В `blog.css` у `.article` вернули боковые поля 20px.** Причина: правило перебивало отступы `.wrap`, на телефоне текст статей прилипал к краю.
